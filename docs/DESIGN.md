# 设计说明：它为什么长这样

这份文档讲**机制与理由**。想知道"改了上游什么"看 `CHANGES-vs-upstream.md`。

---

## 1. 两条链，一个家目录

```
         ┌── 正经轮（定时/手动）  每轮全新会话 ──┐
插件 ────┤                                      ├── cwd 都是 $BILI_DUTY_HOME
         └── 私信轮（常驻会话）  ← 包装器插 id ──┘
```

**为什么两条链分开**：正经轮要从搜索读到字幕、翻评论、抽帧，上下文又大又"脏"；
私信轮要的是**像同一个人**。混在一起 ⇒ 要么她聊天时被一堆视频噪声淹没，要么刷视频时被闲聊污染。

**为什么共享记忆反而是对的**：两条链 `cwd` 相同 ⇒ 记忆库（`<cwd>/.dsh-meow/memory.db`）
**天然就是同一份**，零桥接。于是「私信里随口说的一句偏好」会进记忆库、**下一轮挑视频就读到了**。

## 2. 记忆分三层（这是整套东西的骨架）

| 层 | 放什么 | 为什么 |
|---|---|---|
| **固定文档**（`AGENTS.md` / 用户级 `~/.agents/AGENTS.md`） | **稳定不变**的：你是谁、你的偏好、红线、长期约定 | 它**每次会话开头自动加载**，不占检索成本；判据是"这条两年后还成立吗" |
| **记忆库**（meow-memory） | **会变**的：项目进展、决策、教训、踩过的坑 | 按需检索；写入时就整理（**"事后整理"是假的** —— 等于指望自律）|
| **历史语料 RAG**（`rag.db`） | **素材**：日报、单条笔记、归档、判重表 | 量大、只在"这条是不是见过 / 以前推过什么"时才需要查 ⇒ 不占记忆库 |

> 一句判据：**会变的 → 记忆；不会变的 → 文档；海量的 → RAG。**
> 配套的检索协议写成了一份 DSH skill（`memory-recall`）：catalog 里只占一行，正文按需加载。

## 3. 人设与反馈台账：为什么放在文件里

- 那一轮的 `cwd` 就是家目录 ⇒ `AGENTS.md` 会被**自动加载**（实测过：放个暗号它答得出来）。
- 于是人设分六节：**核心区（不得改）/ 演进区（她自己可以改）/ 反馈台账 / 主人偏好 /
  工具说明 / 回私信的风格**；后四节用 `<!-- -->` 标记，**供脚本整段替换**。
- **文件桥**：宿主每天（08:30）把「收到的赞 / 收藏夹 / 私信里的口头反馈」写进台账区 ⇒
  那一轮自动读到 ⇒ 反馈能反作用于判据。代价是**滞后一天**（想要更快就走共享记忆那条路）。
- `personaPrompt` 只填一段**文字指针**（"严格按当前工作目录的 AGENTS.md 来"）——
  ⚠️ 不能填路径：上游那个"填路径就自动读文件"的特性在非 Windows 平台会**静默失效**。

## 4. 反馈闭环：三个信号源 + 两条通路

| 信号源 | 强度 | 注意 |
|---|---|---|
| **私信里他说的话** | 最强 | 共享记忆 ⇒ 自动进库、下一轮就读到 |
| **收到的赞**（主号赞了小号的评论）| 中 | ⚠️ 这个列表**读一次就清空** ⇒ 必须当天抓、立刻落盘，台账是唯一留档 |
| **主号公开收藏夹** | 中 | 小号只能读 |

**两条通路**：文件桥（每天一次、滞后一天）+ 共享记忆（当轮生效）。
**边界**：这仍然是**提示词层面的加权**，硬约束只有 perDay / 窗口 / 判重表 —— 别把它当推荐算法。

## 5. 判重：从"BV 精确匹配"到"语义判重"

`seen.md` 是逐行记账（BV 号），能挡住重复推送；但它挡不住**同一内容换个 BV 重传**。
所以另建了本机 RAG：相关用例的相似度落在 0.65~0.77，而"库里根本没有的"最高只到 ~0.46 ⇒
**以 0.55 当"找到 / 没找到"的判据**，查不到就如实说"没见过"，**不拿相近条目顶替**。

## 6. 无人值守的保障：把每一次静默失败变成一步检查

| 检查 | 它防的是 |
|---|---|
| **失败轮次检查** | 轮次"烧掉了名额却没跑成"（空闲睡眠冻死是最常见原因）|
| **headless 基线自检** | 某个插件的定时器没 unref ⇒ 那一轮**永久挂死** |
| **私信会话占用检查** | 常驻会话被别的进程攥着写句柄 ⇒ 回复**静默降级**成"没有逐字历史" |
| **RAG 索引增量** | 索引落后于日报 |
| **会话归档** | 会话目录无限膨胀（永远跳过私信链）|

> 原则：**每遇到一次"静默失败"，就把它变成一步自动检查** —— 不报错的失败最贵。

## 7. 已知取舍（诚实清单）

1. **值班轮仍是一个"能读全盘"的进程**（在 2.0.4 上）⇒ 红线靠章程与人设守，**不靠沙箱**。
2. **文件桥滞后一天**；想要即时反馈得靠共享记忆那条路。
3. **反馈仍是指示性的**：真正的硬约束只有配额、窗口、判重表。
4. **长视频转写**是整轮最慢的一环（实测一轮 73 分钟），已有 30 分钟上限可调。
5. **补丁与上游版本绑定**：上游改函数体就得按新版本反推补丁素材。
