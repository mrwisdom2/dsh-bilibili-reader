# 记忆与历史检索（按需）

## 为什么会有这份协议

2026-10-23 起，**每条消息的记忆注入全部关掉了**：
- meow-memory 的 `hitTopK = 0`（原来每条消息按关键词命中注入 2 条）
- dsh-memory-semantic 的 `turns.recallShadow.inject = false`（原来每条消息注入召回原文）

好处是不再每轮塞一大段提示词；**代价是没有任何东西会自动送到眼前**——该查的时候必须主动查。这份文件就是那份协议。

**仍然保留的两项注入（都不是"每次"）**：

| 注入 | 时机 | 有没有开关 |
|---|---|---|
| **首轮长期记忆** | 会话开头注入一次（soul / user / 全局规则 + 记忆导引） | ❌ 没有（meow 只有总开关 `enabled`） |
| **跨会话接力** | 新会话开头几轮里说到「继续/接着/上次/聊到哪…」时，把上个会话的尾巴接进来 | ✅ `sessionRelay.enabled: false`；每会话最多一次 |

## 该用哪个工具

⚠️ **先看第一行** —— 主人的稳定偏好**不在记忆库里**，别去搜（搜了也是空的，那是设计不是丢失）：

| 你想知道 | 去拿 |
|---|---|
| **主人的稳定偏好 / 红线 / 身份**（他怎么要求我做事、B站 双号、Dora 的名字规则…） | **`~/.agents/AGENTS.md`** —— 它**每次会话开头自动加载**，就写在你的上下文里，**不需要检索**。若要改，直接编辑那个文件（用户级、所有工作区生效）。⚠️ 这些内容 2026-10-23 已从记忆库 `user` 层**迁出**，所以 `memory_search` 搜偏好**必然搜不到**——别据此说"没有偏好" |
| **项目类的偏好 / 口径**（如"评论上限两条""私信别自己分条"） | 该项目的人设/台账文件（例：`~/.dsh/bili-duty/AGENTS.md` 的「主人偏好」区）或 `memory_project(项目名)` |
| 某条**结论 / 事实 / 决策** | `memory_search`（关键词 BM25）→ 不满意就换 `memory_semantic`（向量+BM25 融合，**换个说法也找得到**）|
| **一个项目的全貌**（目标 / 结构 / 决策 / 原话 / 待办） | `memory_project(项目名)` ⭐ 一次拿全，比搜准 |
| **关系网**（哪几条重要、哪些是一类） | `memory_graph` |
| **当时怎么说的**（逐字原话、细节） | `recall_turns`（对话原文库）|
| 某条记忆的全文 / 想改它 | `memory_read` / `memory_update` |
| **刷B站推过什么** | `search_finds`（语义检索历史语料）/ `have_seen(bvid)` |

## 五条纪律

1. **先查再答**：凡是"以前 / 上次 / 是否重复 / 是不是聊过"的问题，先检索。用"我记得好像…"糊过去是最坏的回答。
2. **查不到就说查不到**：`search_finds` 里 **低于 0.55 基本等于没找到**（实测：相关的 0.65~0.77，库里根本没有的最高只到 ~0.46）⇒ 如实说"没见过"。**别拿相近条目顶替**，那比不知道更糟。
3. **检索是免费的**（全在本机：BM25 + 本地 bge-m3 向量，零 API 成本）⇒ 多查几次、换个说法再查都不亏。
4. **记忆是过去某个时点的快照**，可能过时：冲突时以**最新时间戳**为准，并顺手 `memory_update` 把过时那条改掉或归档——别让错误记忆留在库里。
5. **该写就写**：出现新事实 / 新决策 / 被用户纠正 / 踩了坑时，用 `memory_remember` 记下来，并按层级归类（`user`=用户偏好、`project`=项目、`lesson`=教训、`fact`=原子事实、`rules`=准则）。**别记流水账**，一句话能说清就别写一段。

## 边界

- 检索工具**只读**；真正的整理与归档交给 dream（记忆整理）和每日 08:30 任务，别抢它们的活。
- 检索结果**可能来自别的会话 / 别的窗口**——引用时标明来源与时间，别当成"刚刚发生的事"。
- `search_finds` 只覆盖刷B站语料（日报 / 单条笔记 / 归档 / 判重表），**不含对话**——要翻对话用 `recall_turns`。
- 涉及"要不要重复做一件事"（比如再推荐一条视频）时，**必须先 `have_seen` / `search_finds` 查过**再下结论。
- **两个工作区的记忆库是分开的**：`default-workspace/.dsh-meow/memory.db`（对话侧）与 `~/.dsh/bili-duty/.dsh-meow/memory.db`（两条链）——在一个库里搜不到的东西，可能在另一个库里。
